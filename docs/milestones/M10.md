Model: sonnet; doc-drafter (haiku) for README text | Time: week 12 to 14
Read first: docs/benchmarks.md, docs/overview.md

## Task
- Prometheus metrics: slot lag in bytes, latency from Postgres commit to view commit,
  transactions and rows applied per second, output delta size, state size, subscriber count and drops.
- OpenTelemetry spans around each apply step and each operator.
- cmd/dvbench runs every benchmark in docs/benchmarks.md and writes CSV.
- A small demo page that subscribes over SSE and shows revenue_by_city updating while a load generator writes.
- README: pitch, architecture diagram, measured numbers, how to run the demo, limitations.

## Definition of done
Benchmarks run with one command. The demo runs with docker compose up.
